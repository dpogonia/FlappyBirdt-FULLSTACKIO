# FlappySwift

Flappy Bird in SpriteKit. A Fullstack.io course sample.

## What it does

The bird flies between pipes. A tap lifts it. Points are scored for each gap it clears.

## Course

A fork of [newlinedotco/FlappySwift](https://github.com/newlinedotco/FlappySwift). It is a sample from the Fullstack.io course Game Programming with Swift. The sample was written by Nate Murray and Ari Lerner, based on code by Matthias Gall. The license is MIT.

The repository now lives under the newline organization, which Fullstack.io became part of.

## Stack

SpriteKit.

## Run

```bash
git clone https://github.com/dpogonia/FlappyBirdt-FULLSTACKIO.git
cd FlappyBirdt-FULLSTACKIO
open FlappyBird.xcodeproj
```

Run the **FlappyBird** scheme on an iPhone simulator. The project targets an old iOS version. If the scheme will not start, raise the deployment target in the target settings.
