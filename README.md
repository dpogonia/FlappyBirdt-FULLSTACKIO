# FlappySwift

Flappy Bird на SpriteKit. Учебный пример курса Fullstack.io.

## Что умеет приложение

Птица летит между трубами. Касание поднимает её вверх. За пролёт начисляются очки.

## Курс

Форк [newlinedotco/FlappySwift](https://github.com/newlinedotco/FlappySwift). Это пример курса Game Programming with Swift от Fullstack.io. Авторы примера: Nate Murray и Ari Lerner, в основе код Matthias Gall. Лицензия MIT.

Репозиторий сейчас лежит у организации newline: Fullstack.io вошла в её состав.

## Стек

SpriteKit.

## Запуск

```bash
git clone https://github.com/dpogonia/FlappySwift-Fullstack.git
cd FlappySwift-Fullstack
open FlappyBird.xcodeproj
```

Запустите схему **FlappyBird** на симуляторе iPhone. Проект собран под старый iOS. Если схема не стартует, поднимите минимальную версию в настройках таргета.
